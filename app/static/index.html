Methodology Notes & Caveats
  • Circularity Notice: The ungrounded-answer rate for the Gate setup is measured using the same deterministic Python checks the gate implements. It reflects gate execution consistency, not an external accuracy benchmark.
  • Sample Size: With a 30-question test set (20 answerable, 10 traps), observed variations are illustrative and anecdotal; they are not statistically significant.

Problem Statement & Motivation

Open-weight LLMs sound confident but frequently hallucinate factual numbers, invent source IDs, or drift into English when queried in Indic languages. Wrong answers matter most where users depend on advice (e.g. citizens or farmers inquiring about agricultural schemes, land subsidies, or livestock compensation).

Existing open grounding checkers are built and tested primarily for English. Studies report lower detection accuracy on multilingual and low-resource languages, with Hindi and Marathi frequently exhibiting severe hallucination rates. groundgate introduces deterministic, Devanagari-aware verification combined with a verifier-triggered single escalation cascade.

Pipeline Architecture

The harness verifies factual grounding deterministically without an extra LLM call, escalating once to a larger tier-2 model if verification fails, and safely refusing otherwise.

Honest Positioning & Related Work

Grounded-answer gates, RAG evaluation frameworks, and model cascades already exist. Our contributions are (1) Devanagari-aware deterministic grounding checks, (2) a verifier-triggered single escalation policy, and (3) a multilingual benchmark comparing raw vs LLM-as-judge vs deterministic gating.

Known Limitations

  • Gate Scope: The gate catches hallucinated numbers, invalid source citations, token divergence, and language mismatch. It does not catch subtle semantic unfaithfulness if all cited words and numbers match.
  • Small Benchmark: The included 30-question evaluation dataset is exploratory. Larger statistical validation on diverse domains is required.
  • Rate-Limited Free Tiers: Free open-weight endpoints (OpenRouter :free and NVIDIA API Catalog) enforce tight RPM limits and may log prompts.
